Данная инструкция нужна для обновления сертификата требуемого для работы с API сервиса "Мгновенные выплаты" в ТБанк.
Выпуск сертификата осуществляется в кабинете ТБанк Бизнесс, в разделе "Интеграции" и состоит из 6 шагов.

1. Перейдите в подраздел "T-API" и нажмите "Выпуск сертификата".
2. Вам будет предложено выбрать сервис для которого требуется выпустить сертификат, выберите "T-API".
3. Далее проверьте данные и если всё верно нажмите "Подтвердить и продолжить".
4. Далее Вам будет предложено выбрать вариант подписания заявки. Выберите подписание через сервис ЭДО, появится инструкция из трёх пунктов:
   ![[tbank_cert_gen_form.png]]
   * п.1) ссылки на скачивание файлов **заявки** и **приватного ключа**. **Заявка** будет в формате PDF, а **приватный ключ** в виде файла с расширением .key - данный ключ очень важен и понадобится для работы с API ТБанка.
     *Важно! У Вас не будет больше возможности скачать файл ключа, поэтому его важно скачать на текущем этапе и не потерять*.
   * п.2) подписание заявки - для подписания нужно передать PDF-заявку Елене Штрик или Аракс Газарян, они в свою очередь отправят заявку кому требуется (предыдущие заявки подписывал СЕО - Егор Егерев). 
   <p><i>Памятка о подписании PDF-заявки на случай вопросов от бухгалтерии что за заявка и что с ней делать:</i></p>
     + [Сайт для подписания эцп][https://crypto.kontur.ru/sign].
     + [Инструкция как подписать][https://uar.ru/ie.pdf].
   * п.3) форма для загрузки файла подписи - после подписания заявки Вам пришлют несколько файлов, среди них должен быть файл с расширением .sig, его нужно загрузить в данную форму (в случае отсутствия такого sig-файла вероятно подойдёт pdf-файл из присланного набора файлов).
5. После загрузки файла подписи будет создан *сертификат*, его нужно скачать. Далее необходимо написать письмо на адрес технической поддержки ТБанка eacq_support@tbank.ru. К письму приложите файл *сертификата*, а в тексте письма напишите, что нужно добавить данный *сертификат* к терминалу сервиса "Мгновенные выплаты" и укажите номер терминала (продовый *TINKOFFPAYOUT_TERMINAL_KEY* в сервисе Vibe).
   *Примечание! Предположительно можно добавить сертификат к терминалу самостоятельно если текущий сертификат ещё не истёк, для этого можно попробовать воспользоваться api-методом [AddCertificate][https://www.tbank.ru/kassa/dev/payouts/index.html#tag/Metody-raboty-s-sertifikatami]*
6. Затем необходимо переформатировать файл приватного ключа скачанного на шаге 4.1 следующей командой: 
   ```
	openssl rsa -in N-private.key -out N-private_rsa.key -traditional
	``` 
	где N это число из названия Вашего файла ключа. Полученным переформатированным ключом нужно заменить старый приватный ключ в 
	*vault->tinkoff->**production**->private_key* и так же заменить его для **stage** и **develop**.
