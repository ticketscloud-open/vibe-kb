[[Checkpoint-Admin]]

Для настройки количества проходов по категории откройте [раздел категорий](https://check.ticketscloud.com/brain#/ticketset) в [[Checkpoint-Admin|админке]].

- Пользуясь фильтрами найдите необходимую вам категорию и нажмите **РЕДАКТИРОВАТЬ (EDIT)**.
- В отрывшейся форме редактирования меняйте поле **Макс. проходов (Max uses)** для настройки кол-ва проходов для всех билетов категории
- Нажмите **СОХРАНИТЬ (SAVE)** для применения изменений

> [!warning] После внесения изменений, сканнерам необходимо перезагрузить билеты если они уже были загружены
