> [!info] База знаний Vibe – архив статей по проектам Vibe

## Начало работы

1. Вам потребуется доступ в git-репозиторий [ticketscloud/vibe-kb](https://github.com/ticketscloud/vibe-kb), убедитесь что он у вас есть или попросите вашего менеджера выделить его.
2. Скачиваем git-репозиторий:
```
git clone https://github.com/ticketscloud/vibe-kb.git
```
3. Далее потребуется [[Obsidian]] который нужно будет скачать и установить [по ссылке](https://obsidian.md/download)
