Начислить денежные средства (или бонусы) на счёт пользователя можно в [[Vibe-Admin|админке Vibe]]:

1. После [[Vibe-Admin#Авторизация|авторизации]] в админке перейдите в [раздел "Клиенты"](https://app.vibeapp.ru/v2/brain#/customer) (**Customers**)
2. Найдите необходимого пользователя для начисления, например используя фильтр по номеру телефона.
3. Кликните по выбранному пользователю
4. В открывшемся окне просмотра в правом углу кликнете по ссылке **БАЛАНС** **(BALANCE)**

![[customer1.png|300]]

5. Появится окно изменения баланса пользователя:
![[balance-form.png|400]]

6. В данном окне первая строка ввода **Начислить (Mint)** предназначена для пополнения, вторая строка ввода **Сжечь (Burn)** предназначена для списания средств. Селектор внизу предназначен для выбора валюты (**RUB**, **USD**, **BONUS_RUB**). Для работы с бонусами выбирайте **BONUS_RUB**.

7. Нажмите **ПРИМЕНИТЬ (START)** для проведения операции

> [!note] Проверка
> Для проверки еще раз откройте окно **БАЛАНС (BALANCE)**. В верхней части окна вы увидите балансы пользователя.

![[balance-form-2.png|400]]
