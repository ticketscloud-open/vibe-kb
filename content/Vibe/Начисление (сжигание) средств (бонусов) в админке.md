Начислить денежные средства (или бонусы) на счёт пользователя можно в [[Vibe-Admin|админке Vibe]]:

1. После [[Vibe-Admin#Авторизация|авторизации]] в админке перейдите в [раздел пользователей](https://app.vibeapp.ru/v2/brain#/customer) (**Customers**)
2. Найдите необходимого пользователя для начисления, например используя фильтр по номеру телефона.
3. Кликните по выбранному пользователю
4. В открывшемся окне просмотра в правом углу кликнете по ссылке **BALANCES**

![[customer1.png|300]]

5. Появится окно изменения баланса пользователя:
![[balances.png|400]]

6. В данном окне первая строка ввода (**Mint**) предназначена для пополнения, вторая строка ввода (**Burn**) предназначена для сжигания. Селектор внизу предназначен для выбора валюты (**RUB**, **USD**, **BONUS_RUB**). Для работы с бонусами выбирайте **BONUS_RUB**.

> [!danger] Обратите внимание
> Сумма указывается в копейках (центах), то есть для суммы 100 руб, необходимо вводить 10000, для суммы 30 руб 42 коп необходимо ввести 3042.

7. Нажмите **START** для проведения операции

> [!note] Проверка
> Для проверки еще раз откройте окно **BALANCES**. В верхней части окна вы увидите балансы пользователя.
