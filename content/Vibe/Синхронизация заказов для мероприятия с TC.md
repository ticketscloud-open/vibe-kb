[[Vibe-Admin|Админка Vibe]] - [[Vibe-Admin Events]]

Используется для синхронизации билетов если по каким то причинам они не импортировались в Vibe.

> [!warning] Если вам нужно синхронизировать билеты только из **одного** заказа то используйте [[Синхронизация заказа с TC]]

Найдите в [разделе событий](https://app.vibeapp.ru/v2/brain#/event) нужное вам событие используя необходимые фильтры.
Кликните по нему чтобы открыть экран просмотра.
Найдите действие **СИНХРОНИЗИРОВАТЬ (SYNC)** в правом верхнем углу и кликните по нему.

Появится форма подтверждения:

![[sync-order-confirm.png|400]]

При нажатии на кнопку **ПОДТВЕРДИТЬ (APPLY)** будет запущена задача по синхронизации информации по билетам для выбранного мероприятия.

> [!danger] Операция может быть запущена не чаще раза в 24 часа для каждого мероприятия
