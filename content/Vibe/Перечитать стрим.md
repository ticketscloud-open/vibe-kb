[[Vibe/|Vibe]] - [[Technical FAQ]]

Команда запустить чтение и обработку стрима (не указывайте topic для процессинга всех)

```bash
$ muffin vibe streams <topic>
```

Чтобы перечитать топик с начала задайте новый **group id**

```bash
$ muffin vibe streams <topic> --group-id=NewGroupID
```

Чтобы читать с какого-либо **offset**:

```bash
$ muffin vibe streams <topic> --offset=<offset>
```

> [!warning] Меняйте **GROUP_ID** если сбрасываете offset
> Иначе повлияете на offset для production (тк по умолчанию GROUP ID берется из настроек)

## Переменные окружения

- **VIBE_IMPORT_ORDERS_LIFETIME_DELTA** - время жизни заказа (сек). Заказы старше этой дельты будут считаться просроченными и не будут обрабатываться
- **VIBE_IMPORT_ORDERS_ONLY_EVENT** - обрабатывать заказы только из этого мероприятия (external_id)
