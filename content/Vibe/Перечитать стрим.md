[[Vibe/|Vibe]] - [[Technical FAQ]]

Команда запустить чтение и обработку стрима (не указывайте topic для процессинга всех)

```bash
$ muffin vibe streams <topic>
```

Чтобы игнорировать оффсет задайте новый **group id**

```bash
$ VIBE_KAFKA_GROUP_ID=something_new muffin vibe streams <topic>
```
