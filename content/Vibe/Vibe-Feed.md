[[Vibe/|Vibe]]

Лента Vibe отображает все доступные для продажи мероприятия в приложении Vibe (веб и Telegram).

## Содержание Ленты

В ленте выводятся два основных типа контента:

- **Промо-блоки:** Эти блоки создаются и управляются через [[Vibe-Admin|админ-панель]].
- **Мероприятия:** Мероприятия попадают в ленту после успешного завершения сделки с Vibe.

Мероприятия группируются по метаданным. Для событий с несколькими сеансами отображается только одна позиция с указанием **минимальной цены** для группы.

## Сортировка

Пользователям доступны следующие варианты сортировки мероприятий в ленте:

- **Тренды:** Мероприятия сортируются по рейтингу, который поступает из внутреннего кабинета Vibe.
- **Ближайшие:** Мероприятия сортируются по минимальной дате начала.

> [!note] Примечание
> Сортировка промо-блоков задается напрямую в [[Vibe-Admin|админ-панели Vibe]].

## Фильтрация

### Фильтрация Промо-блоков

Активные промо-блоки фильтруются по:

- **Выбранному городу:** Если город не указан для промо, оно отображается для всех городов.
- **Дате окончания промо:** Если дата окончания не указана, промо отображается до момента его ручного отключения.

> [!warning] Важно
> Промо-блоки отображаются только в том случае, если пользователь не применил никаких фильтров, кроме фильтра по городу.

### Фильтрация Мероприятий

Мероприятие будет выведено в ленте, если выполнены следующие условия:

- Заключена сделка с Vibe.
- Мероприятие не скрыто из ленты в **админ-панели Vibe**.
- Дата начала мероприятия ещё не наступила.
- Мероприятие не было отменено.

Помимо этих условий, доступны следующие фильтры:

- **Даты начала/окончания мероприятий**
- **Возрастной рейтинг**
- **Город**
- **Организатор**
- **Категория** (влияет на работу фильтра по городу)

Также доступен **поиск по совпадению** вводимого слова с информацией о мероприятии.
#### Особенности фильтрации по городу

Фильтр по городу обычно фильтрует мероприятия по месту их проведения. Однако есть исключения, когда он используется совместно с фильтром по категории:

- **Выбрана только категория "Фестивали":** В этом случае фильтр по городу игнорируется, и отображаются все фестивали, независимо от города.
- **Выбрано несколько категорий, включая "Фестивали":** Мероприятия из запрошенных категорий фильтруются по городу, но это не относится к мероприятиям из категории "Фестивали".
