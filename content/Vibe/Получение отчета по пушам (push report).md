## Получение отчета

Для получения отчета по отдельному push-сообщению зайдите в раздел в админке Vibeapp – [Pushes](https://app.vibeapp.ru/v2/brain#/push). После этого нажмите кнопку `SHOW` интересующего push-сообщения. 

> [!warning] Получение отчета доступно **только для отправленных сообщений**.

![[create_report.png]]
По умолчанию в разделе `Statistics` отображается количество отправленных сообщений `sent`.
Для получения отчета по полученным и открытым push-сообщениям необходимо нажать кнопку `CREATE REPORT` внизу слева, после чего на месте это кнопки появится значок загрузки ![[circular_progress.png]]. После завержения создания отчета в этом же месте отобразится кнопка `DOWNLOAD REPORT`, нажав на которую можно скачать отчет в формате `csv` (это может быть один файл или gz-архив).

## Форма отчета

![[report.png]]
### Дата
Дата отправки push-сообщения.

### Название события
- notification_received  
    показывает количество сообщений, полученных пользователями

- notification_opened  
    показывает количество сообщений, открытых пользователями

### Название параметра
Значение в этой ячейке всегда одно - `push_id`.

### Значение параметра

Значение параметра `push_id`, совпадает с ID push-сообщения в админке.

### Уникальные события с параметрами (d)

Показывает числовое значение для событий `notification_received` и `notification_opened`.
