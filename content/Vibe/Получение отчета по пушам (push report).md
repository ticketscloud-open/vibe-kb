## Получение отчета

Для получения отчета по отдельному push-сообщению зайдите в раздел в админке Vibeapp – [Pushes](https://app.vibeapp.ru/v2/brain#/push). После этого нажмите по интересующему push-сообщению. 

> [!warning] Получение отчета доступно **только для отправленных сообщений**.

В поле `sent` отображается кол-во отправленных сообщений.

Для получения отчета по полученным и открытым push-сообщениям необходимо нажать кнопку **ЗАПРОСИТЬ ОТЧЕТ (PUSH REPORT)** справа вверху, после чего подождать когда кнопка изменит свое состояние на **СКАЧАТЬ ОТЧЕТ (DOWNLOAD REPORT)**, нажав на которую можно скачать отчет в формате `csv` (это может быть один файл или gz-архив).

## Форма отчета

![[report.png]]
### Дата
Дата отправки push-сообщения.

### Название события
- notification_received  
    показывает количество сообщений, полученных пользователями

- notification_opened  
    показывает количество сообщений, открытых пользователями

### Название параметра
Значение в этой ячейке всегда одно - `push_id`.

### Значение параметра

Значение параметра `push_id`, совпадает с ID push-сообщения в админке.

### Уникальные события с параметрами (d)

Показывает числовое значение для событий `notification_received` и `notification_opened`.
